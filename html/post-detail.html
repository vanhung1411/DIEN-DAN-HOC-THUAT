Lỗi Concurrent State Mutation trong React Redux Toolkit Query khi thực hiện Optimistic Update?

Chào mọi người trong cộng đồng, hiện tại nhóm mình đang làm đồ án chuyên ngành TMĐT. Khi khách hàng thao tác tăng số lượng sản phẩm liên tục (click spam 3-5 lần/giây), bọn mình dùng kỹ thuật Optimistic Update với updateQueryData. Tuy nhiên console thỉnh thoảng ném cảnh báo Immer Proxy... 

async onQueryStarted({ itemId, delta }, { dispatch, queryFulfilled }) {
  const patchResult = dispatch(
    cartApi.util.updateQueryData('getCartSummary', undefined, (draft) => {
      const item = draft.items.find(i => i.id === itemId);
      if (item) {
        item.quantity += delta;
      }
      return draft; // <-- Nghi vấn trigger lỗi tại điểm này
    })
  );
}
